Key Takeaways — Recovery Architecture

  • Attackers target backups — design for the case where they already have domain admin
  • 3-2-1 is the starting point, not the destination — add immutability, air-gap, identity separation
  • Immutable retention must exceed your worst-case dwell time (target 90+ days)
  • Recovery sequencing is not optional — identity infrastructure before everything else
  • The only restore test that matters is the one you have actually run recently
